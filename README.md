# VibeCode - AI Tutor Platform 🚀✨

A modern, GenZ/Millennial-themed AI Tutor platform where students can create personalized AI tutors, upload custom lessons, and learn at their own pace.

## Features 🌟

- **Custom AI Tutors**: Create personalized tutors with your choice of:
  - Language (English, Spanish, French, German, Japanese, and more)
  - Subjects (Math, Science, Programming, Languages, etc.)
  - Difficulty levels (Beginner to Expert)
  - Skills focus areas

- **Avatar Selection**: Choose from multiple avatars that speak in your preferred language with different voice types

- **Multi-Format Lesson Upload**:
  - PDF documents
  - Word files
  - Images
  - Videos
  - Audio files
  - Website URLs as references

- **Interactive Lesson Viewer**:
  - Audio/Video playback
  - Charts and visualizations
  - Text and code snippets
  - Reference materials
  - Pause and resume functionality
  - Progress tracking

- **Marketplace**:
  - Browse published lessons
  - Free and paid content
  - Rating and review system
  - Search and filter capabilities

- **Dashboard**:
  - Track your tutors and lessons
  - View statistics and ratings
  - Manage your content

## Tech Stack 💻

- **Frontend**: React 18 + TypeScript
- **Build Tool**: Vite
- **Styling**: TailwindCSS with custom GenZ/Millennial theme
- **Animations**: Framer Motion
- **State Management**: Zustand
- **UI Components**: Radix UI
- **Icons**: Lucide React

## Getting Started 🎯

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open your browser and navigate to `http://localhost:3000`

## Build for Production 📦

```bash
npm run build
```
